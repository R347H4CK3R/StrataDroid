# StrataDroid
Android-native Strata-style launcher for Android 8+ including installed-app library, Home, Cinematic, Big Picture, and GitHub release sources. APKs are distinguished from source-only/iOS packages. Installation requires explicit Android approval.

This is a launcher and GitHub APK source manager. It does **not** run iOS IPA apps, nor does it include a Windows/game emulation engine. APKs from GitHub releases are third-party packages and must be evaluated before installation.

Build: GitHub Actions / Build StrataDroid APK -> download debug APK artifact.
